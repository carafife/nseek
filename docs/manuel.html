Présentation01

Nseek est un client IA natif pour Linux, construit avec GTK4 et Python. Il permet d'interagir avec les modèles DeepSeek V4 directement depuis le bureau GNOME.

✨ Fonctionnalités clés
  • Chat IA en streaming temps réel
  • Historique sauvegardé localement (JSON)
  • Éditeur de code avec coloration syntaxique (GtkSourceView 5)
  • Exécution du code depuis l'éditeur
  • Persona configurable
  • Sélecteur de 10 langues
  • Pièces jointes (texte, PDF)
  • Thème clair et sombre
  • Impression des conversations
Nseek fonctionne sur Linux avec GNOME/Wayland. Une clé API DeepSeek est requise.
⚙️Installation et démarrage02
📦 Dépendances
dnf install python3-gobject gtk4 gtksourceview5 python3-pip
pip install pypdf cairosvg --break-system-packages
🚀 Lancement
python3 ~/Programmes/nseek.py
🔑 Clé API

Créez votre clé sur platform.deepseek.com et enregistrez-la dans :

~/Documents/cle_deepseek_v4_api.txt
Votre clé API est sensible — ne la partagez jamais.

🎭Le Persona05

Le Persona est une instruction permanente définissant le rôle de l'IA. Cliquez sur ✏️ pour le modifier.

💡 Exemples
  • Tu es un expert Linux Fedora. Donne des réponses concises.
  • Tu es un professeur patient. Explique avec des analogies.
  • Tu es un développeur Python senior. Code pythonique.
  • Tu es un traducteur. Traduis sans commenter.

📚Historique des conversations07

Sauvegardé dans ~/.local/share/deepseek-chat/ (JSON).

🗂️ Gestion
  • + Nouvelle conversation — Démarre une session vierge
  • Cliquer sur une session — Recharge la conversation
  • 🗑 — Supprime la session
  • Ctrl+H — Affiche/masque le panneau
